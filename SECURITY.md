ICARUS is a security research tool. Vulnerabilities in the extension itself (e.g., path traversal in report output paths, unsafe deserialization of saved configs, XSS in exported HTML) should be reported privately.

**Please open a [private security advisory](https://github.com/IcarusSec/ICARUS/security/advisories/new) rather than a public issue.**

Include:
- Extension version (jar filename)
- Burp Suite version
- Steps to reproduce
- Impact assessment

We aim to respond within 7 days.

> Note: Findings *produced by* ICARUS against target applications are by design, not vulnerabilities in the tool itself.
